# Context Capsule v0.3.1

v0.3.1 adds an optional NVIDIA NIM Provider Lab.

This release does not change Context Capsule's default local-first behavior. It adds a controlled external-provider path for Raw vs Capsule experiments using NVIDIA NIM's OpenAI-compatible prototype endpoints.

## What Changed

- Added `app.adapters.llm_provider_adapter`.
- Added provider boundary for:
  - `anthropic`
  - `nvidia`
- Added NVIDIA NIM OpenAI-compatible `/chat/completions` client using the standard library.
- Added `--provider nvidia` to `scripts/compare_raw_vs_capsule.py`.
- Added `--models` and `--output` options to the comparison script.
- Kept NVIDIA reports separate by default: `docs/reports/raw_vs_capsule_nvidia.md`.
- Added tests for:
  - NVIDIA model defaults
  - `NVIDIA_API_KEY` requirement
  - OpenAI-compatible payload shape
  - response text extraction
  - token usage extraction
  - Raw vs Capsule model-plan safety for larger repositories
- Added `docs/reference/nvidia_nim_provider.md`.

## Safety / Honesty Rules

- The normal app still does not call external LLMs.
- NVIDIA calls happen only when the user explicitly runs:

```powershell
.\.venv\Scripts\python.exe scripts\compare_raw_vs_capsule.py --provider nvidia
```

- `NVIDIA_API_KEY` is read only from the environment.
- No API key is written to reports, metadata, command examples, or committed scripts.
- NVIDIA NIM Build endpoints are described as prototype/testing endpoints, not unlimited free production infrastructure.
- No local billing price table is configured for NVIDIA, so reports do not convert usage to cost claims.

## Example

```powershell
$env:NVIDIA_API_KEY = "..."
.\.venv\Scripts\python.exe scripts\compare_raw_vs_capsule.py `
  --provider nvidia `
  --models nvidia/nemotron-3-ultra-550b-a55b deepseek-ai/deepseek-v4-flash `
  --repos dummy `
  --task-limit 1 `
  --output docs\reports\raw_vs_capsule_nvidia.md
```
