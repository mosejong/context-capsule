# Context Capsule v0.3.3

v0.3.3 is the build virtualenv scan exclusion patch.

This release includes the `.build-venv` fix that landed after the v0.3.2 tag. It prevents local build virtual environments from leaking into repository scans, Raw vs Capsule comparison inputs, and release packaging safety checks.

## What Changed

- Added `.build-venv/` to `.gitignore`.
- Added `.build-venv` to `scan_repo()` ignored directory parts.
- Added `.build-venv` to `scripts/compare_raw_vs_capsule.py` raw-context ignore rules.
- Added `.build-venv/` to release package blocked tracked prefixes.
- Added regression tests for:
  - repository scanner ignoring `.build-venv`
  - Raw vs Capsule raw-context builder ignoring `.build-venv`

## Why It Matters

`.build-venv` can contain installed packages and generated dependency files. If it is scanned, Context Capsule can:

- retrieve irrelevant dependency code
- inflate token estimates
- make Raw vs Capsule comparisons unfair
- include local build artifacts in accidental tracked-file paths

This patch keeps the scanner focused on the actual project source and docs.
