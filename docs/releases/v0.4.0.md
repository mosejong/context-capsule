# Context Capsule v0.4.0

v0.4.0 is the retrieval-quality and NVIDIA medium/large experiment release.

This release packages the code-aware chunking groundwork from v0.3.x together with medium/large NVIDIA NIM comparison reports. The important point is not that NVIDIA should be treated as a production runtime; it is that Context Capsule can run optional external-provider experiments while keeping reports run-scoped, key-safe, and honest about what was actually measured.

## What Changed

- Added code-aware chunking groundwork for Python, JavaScript, TypeScript, JSX, and TSX files.
- Verified that code-aware chunks are used by hybrid and indexed retrieval modes.
- Added NVIDIA NIM medium/large comparison reports:
  - [procurement medium repo report](../reports/raw_vs_capsule_nvidia_procurement.md)
  - [rainbow-bridge large repo report](../reports/raw_vs_capsule_nvidia_rainbow-bridge.md)
- Improved Raw vs Capsule report honesty for CC-only runs:
  - Raw accuracy is shown as `not measured` when Raw was not sent.
  - Token reduction is shown as `not measured` when no Raw baseline exists.
  - Repo/model summary tables are generated only from measured rows.
- Kept NVIDIA key handling local:
  - `NVIDIA_API_KEY` is loaded from `.env`.
  - API keys are not written to reports, metadata, or examples.

## NVIDIA Results

### procurement-logistics-ai

```text
Provider: NVIDIA NIM
Models: nvidia/nemotron-3-ultra-550b-a55b, deepseek-ai/deepseek-v4-flash
Raw total: 12/24 (50.0%)
Context Capsule total: 16/24 (66.7%)
Average token reduction: 97.7%
```

Interpretation:

- Context Capsule reduced a ~107K-token raw repo context to ~2.4K-token task packets.
- CC improved the score, but exact metric retrieval around the `98.08%` evidence still needs work.
- This is useful v0.4 evidence: the tool is valuable, but metric-conflict and metric-evidence retrieval should become a v0.4 quality target.

### rainbow-bridge

```text
Provider: NVIDIA NIM
Models: nvidia/nemotron-3-ultra-550b-a55b, deepseek-ai/deepseek-v4-flash
Raw total: not measured (CC-only run)
Context Capsule total: 18/18 (100.0%)
Average token reduction: not measured
```

Interpretation:

- The large-repo CC-only run selected useful files for auth, deploy, and migration-style tasks.
- Raw was intentionally not sent for this run, so this report must not be used as a Raw-vs-CC token-reduction claim.
- Some dot-config/devlog noise is still visible in selected candidates, so retrieval ranking remains an active quality target.

## Safety Notes

- NVIDIA NIM support is optional and external.
- The local app still works without NVIDIA credentials.
- NVIDIA Build endpoints are described as prototype/testing endpoints only.
- This release does not claim production-grade endpoint availability or a production SLA.

## Release Positioning

v0.4.0 moves Context Capsule from "it can generate work packets" toward "it can measure and explain retrieval quality on larger repos." The honest takeaway is:

> Context Capsule can reduce context size dramatically and often improve answer grounding, but high-confidence metric retrieval still needs targeted evaluation and ranking work.
