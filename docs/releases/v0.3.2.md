# Context Capsule v0.3.2

v0.3.2 is the NVIDIA report honesty patch.

This release keeps the optional NVIDIA NIM Provider Lab from v0.3.1, but fixes the parts that could make smoke-test reports look stronger than they really are.

## What Changed

- Added safe smoke-test limits to the Raw vs Capsule comparison script:
  - `--repos`
  - `--task-limit`
- Added local `.env` loading for provider credentials.
- Kept `.env` ignored by git and documented `NVIDIA_API_KEY=...` usage.
- Fixed Windows console output so Unicode score icons do not crash `compare_raw_vs_capsule.py`.
- Regenerated NVIDIA smoke evidence with:
  - repo: `dummy`
  - task limit: `1`
  - model: `nvidia/nemotron-3-ultra-550b-a55b`
- Removed hard-coded old Anthropic summary rows from NVIDIA reports.
- Made repo/model summary tables generated only from rows measured in the current run.
- Added an explicit smoke-test warning when `--task-limit` is used.
- Matched Anthropic and NVIDIA comparison sampling defaults:
  - `temperature = 0.2`
  - `top_p = 0.95`
- Added `nvapi-...` redaction to secret patterns.
- Redacted secret-like values from model-call error messages before writing reports.
- For NVIDIA runs, `procurement` no longer inherits the Anthropic "first model only Raw" cost-saving rule. NVIDIA comparison can measure Raw for all selected NVIDIA models unless the user limits repos/tasks explicitly.

## Safety / Honesty Rules

- Do not describe `--task-limit` reports as full benchmark results.
- Do not mix previous Anthropic numbers into NVIDIA reports.
- Do not claim NVIDIA free endpoints are unlimited production infrastructure.
- Do not store `NVIDIA_API_KEY` in reports, metadata, scripts, screenshots, or command examples.
- Treat NVIDIA NIM endpoints as prototype/testing endpoints unless a separate production contract says otherwise.
- Keep Context Capsule local-first by default. NVIDIA calls happen only when `scripts/compare_raw_vs_capsule.py --provider nvidia` is explicitly run.
