# Context Capsule v0.4.1 Stabilization Checkpoint

This checkpoint records the production-readiness work added after the v0.4.0 tag and before the v0.5 harness feature set.

## Included fixes

- Added repository scan file/byte caps with explicit truncation warnings.
- Skipped symlinks so scans do not read outside the selected repository.
- Strengthened credential-like value redaction without masking ordinary token metrics.
- Allocated output directories atomically to avoid collisions.
- Locked the full validation environment in `requirements.lock`.
- Added RAGAS-style local evaluation and partial Context Recall groundwork.

The changes are retained in v0.5.0. This document is a stabilization checkpoint; it does not claim that a separate GitHub Release has already been published.
