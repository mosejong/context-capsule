# Context Capsule v0.3.0

v0.3.0 starts the Korean RAG quality track.

The goal is not to claim that Context Capsule now has a perfect semantic search engine. The goal is stricter and more useful: keep the fast local retrieval path working, add a measured path for real local embedding candidates, and make retrieval quality claims reproducible.

## What Changed

- Added benchmark support for optional `sentence-transformers` embedding models.
- Added `--embedding-model` to `scripts/benchmark_retrieval_modes.py`.
- Added `--offline` mode for cached/local model testing in closed-network-style environments.
- Added provider visibility for `hybrid` and `indexed` retrieval, including fallback labels.
- Added provider caching so benchmark runs do not reload the same embedding model for every case.
- Added local-only model loading through `CONTEXT_CAPSULE_EMBEDDING_LOCAL_ONLY`.
- Added model input profiles:
  - E5 / KoE5: `query:` and `passage:` prefixes
  - Qwen3 Embedding: query-side instruction format
  - BGE-M3: raw query/passages by default
- Added a measured `ko-sroberta` benchmark report.
- Updated retrieval benchmark docs and reports index.
- Fixed Raw vs Capsule scoring so avoiding known wrong values, such as `98.6` when the evidence-backed value is `98.08`, is counted consistently.

## Why It Matters

v0.2 proved that Context Capsule can turn vague Korean work requests into safer work packets.

v0.3 begins the next layer: retrieval quality should be measurable, comparable, and honest.

This release keeps `hash_local_v1` as the default so the app still works without downloads or external APIs. Real embedding models remain optional and are evaluated through explicit benchmark commands instead of silently becoming the default.

## How To Try The Retrieval Benchmark

Default local benchmark:

```powershell
.\.venv\Scripts\python.exe scripts\benchmark_retrieval_modes.py --modes keyword hybrid indexed
```

Optional local embedding candidate:

```powershell
.\.venv\Scripts\python.exe scripts\benchmark_retrieval_modes.py --embedding-model BAAI/bge-m3 --modes hybrid indexed
```

Cached/local-only mode:

```powershell
.\.venv\Scripts\python.exe scripts\benchmark_retrieval_modes.py --embedding-model jhgan/ko-sroberta-multitask --modes hybrid --offline
```

## What This Is Not

- Not an external LLM integration.
- Not a Token Analyzer adapter.
- Not a paid API requirement.
- Not a claim that every Korean/English repository query is solved.
- Not a default model download on first run.

## Upgrade Notes

- Use Python 3.11 or newer.
- Default app behavior remains external-API-free.
- Optional embedding models require `requirements-rag.txt`.
- If an optional model cannot load, Context Capsule falls back to the built-in hash provider instead of blocking packet generation.
- Benchmark reports are local quality gates, not broad public model leaderboard claims.
